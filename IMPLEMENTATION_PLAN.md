### Task 1C: i18n Architecture Audit — Extract Inline Strings

**Objective:** Eliminate all 39+ files using inline `isRTL ? 'عربي' : 'English'` ternaries. Move all user-facing text to `ar.json` and `en.json`.

**Strategy:** Surgical role-based extraction (no full rewrite).

**File priority order (lowest blast radius first):**

| Priority | Domain | Files | Est. keys |
|----------|--------|-------|-----------|
| 1 | Visitor | 5 page files | ~30 |
| 2 | Auth | 3 modules (Login, Register, Forgot) | ~15 |
| 3 | Shell | Header, Sidebar, BottomNav | ~10 |
| 4 | Owner | 7 page files | ~45 |
| 5 | Carrier | 8 page files | ~50 |
| 6 | Gov | 10 page files | ~60 |

**Per-file procedure:**

1. Grep for `isRTL ?` ternaries and raw Arabic/English literals
2. Add key to both `public/locales/ar.json` and `public/locales/en.json`
   - Follow existing nesting pattern (e.g., `nav.menu.home`, `auth.login.title`)
3. Replace inline string with `t('key.path')` call
4. Remove unused `isRTL` destructuring if all inline strings resolved
5. Verify component renders correctly in both locales

**Example transformation:**
```tsx
// BEFORE
const title = isRTL ? 'تسجيل الدخول' : 'Login';

// AFTER
const { t } = useTranslation();
const title = t('auth.login.title');
```

**Verification command:**
```bash
# After each batch, grep to ensure no inline strings remain
rg "isRTL\s*\?.*'.*'.*'.*'" src/ --type tsx --type tsx
# Should return zero results across entire codebase
```

**Acceptance:** Zero `isRTL ? '...' : '...'` patterns in any `.tsx` or `.ts` file. All text sourced exclusively from locale JSON.

### Task 4C: Auth Pages Responsivity Fix

**Objective:** Fix Login/Register/Forgot pages for mobile/tablet/desktop viewports

**Problem:** `max-w-[480px]` too narrow on tablet, geometric patterns cause mobile clutter

**Files:** `LoginPage.tsx`, `RegistrationModule.tsx`, `ForgotPasswordModule.tsx`

**Breakpoint strategy:**

| Breakpoint | Width | Behavior |
|------------|-------|----------|
| Mobile | `< 640px` | Hide geometric background patterns. Full-width card with `px-4` padding. Larger touch targets. |
| Tablet | `640–1024px` | `max-w-[520px]` card centered. Reduce pattern opacity to 0.3. |
| Desktop | `> 1024px` | `max-w-[480px]` card + full-opacity patterns. Option split layout if design calls for it. |

**Implementation per file:**

```tsx
// Example LoginPage.tsx wrapper
<div className="min-h-screen flex items-center justify-center bg-cover bg-center"
     style={{
       backgroundImage: 'var(--geometric-pattern)', // CSS var to control opacity
       opacity: window.innerWidth < 640 ? 0 : 1, // or use CSS @media
     }}>
  <div className="w-full max-w-[480px] md:max-w-[520px] px-4">
    {/* Card content */}
  </div>
</div>
```

Better approach: Use Tailwind responsive classes with CSS layer:

```css
/* globals.css */
.auth-bg-pattern {
  background-image: url('/patterns/geometric.svg');
  opacity: 0.6;
}
@media (max-width: 639px) {
  .auth-bg-pattern { opacity: 0; }
}
```

Then apply `className="auth-bg-pattern"` to auth page container.

**Verification:**
```bash
# Chrome DevTools responsive mode
# Mobile 375px: No background pattern, card full-width, no horizontal scroll
# Tablet 768px: Card 520px max, subtle pattern at 30% opacity
# Desktop 1440px: Card 480px max, full pattern visible
# Test both RTL (ar) and LTR (en) locales
```

**Acceptance:** No horizontal overflow, all inputs reachable, pattern visibility appropriate per viewport.

### Task 5C: Automated i18n Cleanliness Check

**File:** `scripts/check-i18n-cleanliness.js`

```js
const { execSync } = require('child_process');

try {
  const results = execSync(
    "rg -n \"isRTL\\\\s*?\\\\?.*('.*').*('.*')\" src/ --type tsx",
    { encoding: 'utf8', stdio: ['pipe', 'pipe', 'pipe'] }
  );
  if (results.length > 0) {
    console.error('❌ Inline i18n strings found:\n', results);
    process.exit(1);
  }
  console.log('✅ No inline i18n strings found');
  process.exit(0);
} catch (err) {
  if (err.stdout && err.stdout.length > 0) {
    console.error('❌ Inline i18n strings found:\n', err.stdout);
    process.exit(1);
  }
  // No matches is success
  console.log('✅ No inline i18n strings found');
  process.exit(0);
}
```
