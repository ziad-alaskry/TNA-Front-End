# Technical Implementation Plan: TNA Header Redesign

## 1. Impact Analysis

### Current Structure (header.png)
- **Layout**: Simple two-section flex container
  - Left: Logo (TNA/PLATFORM) with language toggle button
  - Right: Empty space (language toggle actually on left side of logo in code)
- **Styling**: 
  - Solid white background (`bg-white` implied via tokens)
  - No elevation/shadow
  - Basic hover/focus states on language toggle
  - Fixed height with padding (`px-5 md:px-8`)
- **Components**: 
  - Custom logo link with image and text
  - Custom language toggle button with Globe icon
- **Limitations**:
  - Low information density (only logo and language toggle)
  - No navigation context (breadcrumb missing)
  - No search provision
  - No user account controls
  - Not utilizing design system tokens for styling
  - No glassmorphism effect
  - RTL support limited to locale switching only

### Proposed Enterprise Architecture
- **Layout**: Three-section flex container (start-center-end)
  - Start: Breadcrumb component for hierarchical navigation
  - Center: Flexible slot for future GlobalSearch integration
  - End: UserAccount group (LanguageSwitcher, NotificationBell, UserAvatar with dropdown)
- **Styling**:
  - Glassmorphism effect: `backdrop-filter: blur(10px)` with semi-transparent background
  - Elevation: System-driven `elevation-low` token (soft box-shadow)
  - Token-driven: All colors, spacing, radii from SPATIAL design tokens
  - Interactive states: Mapped to design system's interactive color palette
  - Height: Defined by `--navbar-height` token (72px)
- **Components**:
  - Reusable Breadcrumb (from shared/Breadcrumbs.tsx)
  - Reusable LanguageSwitcher (from ui/LanguageSwitcher.tsx)
  - Placeholders for NotificationBell and UserAvatar (to be implemented)
  - Search slot container for GlobalSearch (future integration)
- **Enhancements**:
  - High information density with contextual navigation
  - RTL-ready architecture using logical properties
  - Seamless integration with existing sidebar navigation (z-index management)
  - Enterprise-grade visual consistency with token system

2. Validate elevation token implementation:
   - Confirm shadow doesn't interfere with sidebar elevation

3. Test responsive behavior:
   - Mobile breakpoint: Ensure sections don't collapse incorrectly
   - Verify search slot remains functional at all widths

4. Conduct RTL validation:
   - Switch locale to Arabic and verify layout mirrors correctly

## Refinement Plan: Enterprise-Grade Header Component

### 1. Component Audit & Integration

#### Search/Input Component
- **Target Component**: `tna-project/src/components/ui/InputField.tsx`
- **Current Implementation**: Native `<input>` element with placeholder
- **Refinement**: Replace with standardized `InputField` component
  - Import `InputField` from `@/components/ui/InputField`
  - Apply SPATIAL design specs via `h-input` height token (52px)
  - Use `--surface-200` for background, `--neutral-200` for border
  - Add search icon via `icon` prop (MagnifyingGlass from lucide-react)

#### LanguageSwitcher Refinement
- **Current Style**: Border with background, bold buttons
- **Target Style**: Ghost variant for minimal visual noise
- **Changes**:
  - Replace border/background with `variant="ghost"` from Button component
  - Use `<Button>` components with `variant="ghost"` instead of native buttons
  - Import Button and use ghost styling: hover:bg-neutral-50, text-neutral-500

### 2. Design Token Mapping (Strict CSS Variable Implementation)

| Token | Value | Usage in Header |
|-------|-------|-----------------|
| `--surface-200` | `#FFFFFF` | Header background with alpha: `rgba(255, 255, 255, 0.7)` |
| `--shadow-navbar` | `0 -1px 8px rgba(0, 0, 0, 0.06)` | Box-shadow for depth |
| `--backdrop-blur` | `blur(12px)` | Glassmorphism effect (updated from 10px) |
| `--neutral-200` | `#EAECEE` | Border color with alpha: `rgba(234, 236, 238, 0.5)` |
| `--radius-sm` | `10px` | Input border radius |

**Constraint**: No hardcoded hex values - all must use `rgba()` with CSS variables

### 5. Layout & RTL Optimization

#### Flexbox Structure
```tsx
<header className="flex h-[var(--navbar-height)] items-center justify-between">
  {/* Start: Breadcrumb (flex-shrink-0) */}
  <div className="flex-shrink-0 ps-[var(--space-4)]">
    <Breadcrumbs />
  </div>
  
  {/* Center: Search (perfectly centered) */}
  <div className="flex-1 flex justify-center">
    <div className="w-full max-w-xs">
      <InputField ... />
    </div>
  </div>
  
  {/* End: Controls (flex-shrink-0) */}
  <div className="flex-shrink-0 pe-[var(--space-4)] flex items-center gap-[var(--space-3)]">
    <LanguageSwitcher variant="ghost" />
    <NotificationBell />
    <UserAvatar />
  </div>
</header>
```

#### RTL Positioning
- Breadcrumbs: `ps-4` → `ps-[var(--space-4)]` automatically adapts
- End section: `pe-4` for padding-end
- Flex spacing: `space-x-3` → `gap-[var(--space-3)]`
