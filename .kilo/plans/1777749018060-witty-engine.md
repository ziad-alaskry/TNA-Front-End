## Phase 2: Header Visual Theming (High)

### 2.1 Apply frosted glass + teal accent line to AppShell header

**Current problem:** `AppShell.tsx` header structure:
```tsx
<header className="topbar ui-topbar ps-5 pe-5 py-4 shrink-0">
```

`.ui-topbar` in globals.css defines:
```css
.ui-topbar {
  position: sticky; top: 0; z-index: 50;
  border-bottom: 1px solid var(--neutral-200);
  border-top: var(--header-accent-line);  /* 3px solid var(--primitive-cyan) */
  height: var(--navbar-height);
  background: rgba(255, 255, 255, 0.85);
  backdrop-filter: blur(20px);
  box-shadow: var(--shadow-header);
  transition: all 0.3s;
}
```

**The teal accent line exists** (`border-top: var(--header-accent-line)`) BUT:
- AppShell applies `topbar` + `ui-topbar` — `topbar` is a plain class without styles
- `ui-topbar` already has the teal accent and frosted glass ✅
- However, header height mismatch: `var(--navbar-height)` = 72px but AppShell uses `py-4` (16px) → actual height ~56px. Teal line may be clipped or overflow.

**Fix:** Ensure AppShell header uses consistent height. Either:
- Remove `py-4` from AppShell header and rely on `var(--navbar-height)` from `.ui-topbar`
- OR override `.ui-topbar` height to `auto` and keep `py-4`

**Recommended:** Remove inline padding, let `.ui-topbar` control height:
```tsx
// AppShell.tsx line 45
<header suppressHydrationWarning className="topbar ui-topbar ps-5 pe-5 shrink-0">
```

### 2.2 Smooth visual transition: Header → Sidebar

**Problem:** White frosted header sits above dark navy sidebar → visual disconnect.

**Solution A (Subtle gradient bridge):** Add bottom border to header that transitions from teal to transparent:
```css
.ui-topbar {
  border-bottom: 1px solid transparent;
  background: linear-gradient(
    to bottom,
    rgba(var(--color-white-rgb), 0.92) 0%,
    rgba(var(--color-white-rgb), 0.85) 100%
  );
}
```

**Solution B (Role-aware header):** For Owner/Gov dark themes, header should blend with dark surfaces. Add:
```css
.theme-owner .ui-topbar,
.theme-gov .ui-topbar {
  background: rgba(var(--surface-dark-200-rgb), 0.85);
  border-bottom-color: rgba(255,255,255,0.1);
}
.theme-owner .topbar-title,
.theme-owner .sidebar-brand-name {
  color: #FFFFFF;
}
```

**Decision needed:** Should header be role-aware (light for Visitor, dark for Owner)? Or universal frosted white?

## Phase 3: Language Toggle Theming (High)

**File:** `src/components/ui/LanguageSwitcher.tsx`

**Current issues (lines 43–56):**
```tsx
className="flex items-center gap-1 rounded-md border border-slate-200 bg-slate-100/50 p-1"
// ...
className={`... ${currentLocale === locale
  ? 'bg-primitive-navy text-white shadow-sm'
  : 'text-slate-500 hover:bg-white hover:text-slate-900'}`}
```

- Uses `slate-*` (Tailwind defaults) → outside SPATIAL neutral system
- `bg-primitive-navy` is **invalid** — no such CSS variable (`--primitive-navy` exists, but `bg-primitive-navy` not a utility class)
- Hover states not theme-aware

**Fix:**
```tsx
// Wrapper
className="flex items-center gap-1 rounded-md border border-neutral-200 bg-white/50 p-1"

// Active button
className={`rounded-sm px-3 py-1 text-xs font-bold transition-all duration-200 ${
  currentLocale === locale
    ? 'bg-primary text-white shadow-sm'  // SPATIAL navy
    : 'text-neutral-500 hover:bg-neutral-50 hover:text-neutral-900'
}`}
```

**Result:** Active language = primary navy; inactive = neutral gray, consistent with SPATIAL theme.

## Risks & Mitigations

| Risk | Impact | Mitigation |
|------|--------|------------|
| Logo replacement breaks cached SVGs | Medium | Browsers will re-fetch on Next.js rebuild; add `?v=2` query param if needed |
| Dark header reduces contrast/legibility | High | Test WCAG AA; use white frosted glass for all roles if dark fails contrast |
| LanguageSwitcher refactor breaks SSR hydration | Medium | Component already has `mounted` guard; ensure classNames are deterministic |
| Dual asset locations cause drift | Medium | Document canonical location; add comment in globals.css |
| Header height mismatch causes overflow | Low | Remove `py-4` from AppShell header, rely on `.ui-topbar` height |
