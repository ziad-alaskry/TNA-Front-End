**Enhance `t()` function for interpolation (if needed):**
**File:** `src/i18n/LocaleProvider.tsx:26-37`, `57-68`

Update to support `{variable}` substitution:
```ts
const t = (path: string, params?: Record<string, any>) => {
  const keys = path.split('.')
  let current = context.messages
  for (const key of keys) {
    if (current && current[key]) {
      current = current[key]
    } else {
      return path
    }
  }
  let result = typeof current === 'string' ? current : path
  if (params) {
    Object.keys(params).forEach(key => {
      result = result.replace(new RegExp(`{${key}}`, 'g'), params[key])
    })
  }
  return result
}
```
