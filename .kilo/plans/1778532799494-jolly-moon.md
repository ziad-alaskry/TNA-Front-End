# Task 1C Execution Plan — i18n Architecture Audit (Inline String Extraction)

**Objective:** Eliminate all inline `isRTL ? 'عربي' : 'English'` ternaries across the codebase by extracting them into the i18n locale system.

**Project Structure:**
- Source root: `tna-project/src/`
- Locales: `tna-project/public/locales/ar.json`, `en.json`
- Scripts will be placed in: `tna-project/scripts/`

**Current State Analysis:**
- ~226 inline i18n patterns detected across 39+ files
- Six domains: visitor, auth, shell, owner, carrier, gov
- Existing i18n infrastructure is operational (`useLocale()` hook, `t()` function)
- `glob` package already available in devDependencies

## Phase 1 — Discovery & Schema Generation (Sub-task 1C-0)

### Write Discovery Script

**File:** `tna-project/scripts/i18n-extract.js`

**Config:**
- `SRC_DIR = path.resolve(__dirname, '../src')`
- `LOCALES_DIR = path.resolve(__dirname, '../public/locales')`
- Pattern: `/isRTL\s*\?\s*['"`]([^'"`]+)['"`]\s*:\s*['"`]([^'"`]+)['"`]/g`

**Domain Detection Map:**
```javascript
const DOMAIN_MAP = [
  { pattern: /\/visitor\//, domain: 'visitor' },
  { pattern: /\/auth\//,    domain: 'auth'    },
  { pattern: /\/shell\//,   domain: 'shell'   },
  { pattern: /\/owner\//,   domain: 'owner'   },
  { pattern: /\/carrier\//, domain: 'carrier' },
  { pattern: /\/gov\//,     domain: 'gov'     },
  { pattern: /\/components\/modules\/visitor/, domain: 'visitor' },
  { pattern: /\/components\/modules\/auth/,    domain: 'auth'    },
  { pattern: /\/components\/modules\/owner/,   domain: 'owner'   },
  { pattern: /\/components\/modules\/carrier/, domain: 'carrier' },
  { pattern: /\/components\/modules\/gov/,     domain: 'gov'     },
  { pattern: /\/components\/shell/,            domain: 'shell'   },
  { pattern: /\/components\/layout/,           domain: 'shell'   },
];
```

**Key Generation:**
- Use English string to generate slug: lowercase, strip punctuation, spaces→underscores, max 40 chars
- Prefix with domain: `${domain}.${slug}_${index}` (index prevents collisions)
- Example: `isRTL ? 'التحقق من عنوان TNA' : 'Verify TNA Address'` in `carrier/resolve/page.tsx` → `carrier.verify_tna_address_1`

**Outputs:**
- `tna-project/scripts/i18n-manifest.json` — full list of matches with file, line, arStr, enStr, suggestedKey
- `tna-project/scripts/i18n-patch.json` — nested structure ready to merge into locale files

**Run:** `node tna-project/scripts/i18n-extract.js`

**Expected:** ~226 patterns found across ~39 files, broken down by domain

**CHECKPOINT 1C-0:** Commit discovery script and generated manifest + patch files.

## Phase 3 — Replacement Script (Sub-task 1C-2)

### Write Atomic Replacement Script

**File:** `tna-project/scripts/i18n-replace.js`

**Arguments:** `--domain <name>` (visitor|auth|shell|owner|carrier|gov|all)

**Per-Match Action:**
1. Replace `isRTL ? 'arabic' : 'english'` → `t('domain.key')`
2. Ensure file has `import { useTranslation } from 'react-i18next'`
3. Ensure component destructures `const { t } = useTranslation()`
4. Flag `isRTL` usage for manual review: replace `const { isRTL }` with `/* TODO: review */ const { isRTL }`

**Heuristics for Import Injection:**
- If no `useTranslation` import exists, add it after last import line
- If component already destructures from `useLocale()`, **do not add a second destructure** — instead modify the existing line to include `t`
  - Look for: `const { locale, isRTL } = useLocale()`
  - Change to: `const { locale, isRTL, t } = useLocale()`

**Critical:** The replacement must ONLY target the exact ternary pattern. Do not modify:
- `dir={isRTL ? 'rtl' : 'ltr'}` (not a text string)
- `className={isRTL ? "rotate-180" : ""}` (icon rotation — NOT a translatable string)
- `[isRTL ? 'ar' : 'en']` object accessor pattern (dynamic object lookup, not inline text)

**Target Pattern:** `isRTL\s*\?\s*['"`]([^'"`]+)['"`]\s*:\s*['"`]([^'"`]+)['"`]` within JSX text content

**Processing Flow:**
- Load manifest
- Filter entries by domain prefix
- Group by file
- For each file: read, apply replacements, write back
- Log: `✓ path/to/file.tsx — N replacement(s)`

**CHECKPOINT 1C-2:** Script written and ready for domain loops

## Phase 6 — Post-Extraction Manual Cleanup (Out-of-Band)

The replacement script adds `/* TODO: remove if isRTL no longer used */` markers before `const { isRTL }` destructures.

**Manual Action Required (after verification):**
1. Search for `TODO.*isRTL` comments across codebase
2. For each component:
   - If `isRTL` is ONLY used for the inline ternary strings that were just replaced → remove the destructure
   - If `isRTL` is still used for `dir={isRTL ? 'rtl' : 'ltr'}` or icon rotation → keep it
3. Remove the `cn("rotate-180", isRTL && ...)` patterns by replacing with conditional class only (since rotation is handled by `dir` on parent or keep explicit className logic)

**Note:** This cleanup is **not part of automated Task 1C** — it's a separate manual sweep. Task 1C completes when the gate passes.

## Risk Mitigation

| Risk | Mitigation |
|------|------------|
| Missed strings outside `src/` | Grep entire repo after gate, include `tna-project/src` only per structure |
| className rotation patterns overwritten | Regex targets only text content; rotation classes preserved |
| `isRTL` still needed for dir/rotations | Replacement script adds TODO marker, manual cleanup phase |
| Key naming collisions | Index suffix prevents duplicates |
| Broken import injection | Script checks for existing `useTranslation` and `useLocale` usage |
| Locale file merge conflicts | Deep merge preserves existing manual keys |
