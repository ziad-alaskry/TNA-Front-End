## 📐 Phase 3 — Layout & Positioning (P6, P7)

**Goal:** Fix RTL logo alignment, prevent header element collisions

**Files:**
- `tna-project/src/components/layout/AppShell.tsx` (for mobile sidebar header)
- `tna-project/src/components/shell/Header.tsx` (topbar layout)

**Changes:**

1. **Mobile sidebar header RTL logo align** (P6)
   - Ensure `<html dir="rtl">` is set (already using `dir={t('common.dir')}`)
   - In mobile sidebar header (AppShell lines 127–135), use:
     ```tsx
     <div className="flex items-center justify-between p-5 border-b border-[#c8d6e0] bg-gradient-to-r from-primary to-primary-dark">
       <div className="flex items-center gap-3">  {/* Right-side in RTL */}
         {/* Optional: TNA logo placeholder if needed */}
         <span className="font-bold text-white tracking-tight">{t('common.menu')}</span>
       </div>
       {/* No X button */}
     </div>
     ```
   - Ensure `justify-between` places brand on the RTL start (right) and any remaining space handled correctly

2. **Fix hamburger + logo spacing in topbar** (P7)
   - **Header.tsx** currently has:
     ```tsx
     <div className="flex-shrink-0 ps-[var(--space-4)] flex items-center gap-[var(--space-3)]">
       {/* Hamburger */}
       <button>...</button>
       {/* Logo link */}
       <Link>...</Link>
     </div>
     ```
   - This already has `flex-shrink-0` and `gap-[var(--space-3)]`. Should be sufficient.
   - **Potential issue:** The header has two groups: start-section (hamburger+logo) and end-section (controls). The center is empty. According to guide, structure should be:
     - Right/start: Avatar, Bell, Lang, Balance (flex-shrink-0)
     - Center: Page title (flex: 1, min-width: 0)
     - Left/end: Logo, Hamburger (flex-shrink-0)
   - Current Header structure:
     - Start section: Hamburger + Logo (left side in LTR, right in RTL) — actually acts as left/end group per spec
     - End section: Balance, Lang, Bell, Avatar — these are right/start group in RTL
     - **Missing:** Explicit center group for page title
   - **Solution:** Add a center div with `flex: 1 min-width-0` that contains the title prop if provided, otherwise empty. Ensure it doesn't collapse.
   - **Implementation in Header.tsx:**
     ```tsx
     <div className="h-full flex items-center justify-between px-...">
       {/* Start group (RTL right): user controls */}
       <div className="flex-shrink-0 flex items-center gap-3">...controls...</div>

       {/* Center group: page title */}
       {title && (
         <div className="flex-1 min-width-0 px-4 text-center">
           <h1 className="text-sm font-semibold text-[#1a2736] truncate">{title}</h1>
         </div>
       )}

       {/* End group (RTL left): logo + hamburger */}
       <div className="flex-shrink-0 flex items-center gap-3">...logo+hamburger...</div>
     </div>
     ```
   - This ensures title doesn't collide with either side even on narrow screens.

3. **Mobile sidebar width** (P6)
   - In AppShell mobile sidebar, change `w-72` to `min(280px, 85vw)`
   - Update className: `w-72` → `w-[min(280px,85vw)]` or use arbitrary value `min-w-[280px] max-w-[85vw]`

**Validation checklist for Phase 3:**
- [ ] Mobile sidebar width not full-screen on landscape mobile (max ~85% width)

- [ ] Topbar title displays centered without overlapping left/end elements

## ⚠️ Dependencies & Risks

- **Risk:** Changing desktop sidebar from dark to white may require updating icon colors for visibility
- **Mitigation:** Use dark icon colors (`#374151` or `#6b7a8d`) for collapsed/expanded states
- **Risk:** Header restructure may break existing layout in other pages
- **Mitigation:** Make changes within existing `flex` structure, use utility classes only, test in both RTL/LTR
- **Risk:** z-index war with existing components (modals, dropdowns, notification panel)
- **Mitigation:** Use CSS variables for z-index; verify no other component uses 500+ unintentionally
