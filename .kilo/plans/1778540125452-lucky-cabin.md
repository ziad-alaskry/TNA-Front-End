# Quick Fix Plan — Task 1C Remaining i18n Issues

**Objective:** Eliminate the 3 remaining inline `isRTL` ternary patterns that escaped regex-based extraction.

**Root cause:** The discovery regex only matches simple `isRTL ? 'str' : 'str'` patterns. It fails on:
- Nested ternaries (conditional inside conditional)
- Template literals with interpolation

**Scope:** 3 files, 4 Arabic strings, 2 English strings, 1 reusable template.

---

## Changes Required

### 1. `src/app/[locale]/gov/address-queue/[id]/page.tsx` (line 112)

**Current:**
```tsx
<h3>{isRTL ? (decision === 'APPROVED' ? 'تم التحقق' : 'تم الرفض') : `Request ${decision}`}</h3>
```

**Fix:**
```tsx
<h3>{isRTL 
  ? t(decision === 'APPROVED' ? 'gov.address_verified' : 'gov.address_rejected')
  : t('gov.request_decision', { decision })
}</h3>
```

**Add to `public/locales/ar.json` (under `gov` domain):**
```json
"address_verified": "تم التحقق",
"address_rejected": "تم الرفض",
"request_decision": "Request {decision}"
```

**Add to `public/locales/en.json` (under `gov` domain):**
```json
"address_verified": "Address Verified",
"address_rejected": "Address Rejected",
"request_decision": "Request {decision}"
```
