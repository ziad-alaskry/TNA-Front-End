## Phase 2: Language Toggle Theme Alignment (High Priority)

**File:** `src/components/ui/LanguageSwitcher.tsx` (lines 43–56)

### 2.1 Current issues
```tsx
className="flex items-center gap-1 rounded-md border border-slate-200 bg-slate-100/50 p-1"
// ...
className={`... ${currentLocale === locale
  ? 'bg-primitive-navy text-white shadow-sm'  // ❌ invalid: no bg-primitive-navy class
  : 'text-slate-500 hover:bg-white hover:text-slate-900'}`}
```
- Uses `slate-*` (Tailwind defaults) → outside SPATIAL neutral system
- `bg-primitive-navy` is **not a valid Tailwind utility**; should use `bg-primary` or `bg-brand-navy`
- Inactive hover uses `bg-white` instead of neutral tokens

### 2.2 Fix: Apply SPATIAL color tokens

**Wrapper (neutral background):**
```tsx
className="flex items-center gap-1 rounded-md border border-neutral-200 bg-white/50 p-1"
```

**Active button (SPATIAL navy):**
```tsx
className={`rounded-sm px-3 py-1 text-xs font-bold transition-all duration-200 ${
  currentLocale === locale
    ? 'bg-primary text-white shadow-sm'  // PRIMARY = #02488D from globals.css
    : 'text-neutral-500 hover:bg-neutral-50 hover:text-neutral-900'
}`}
```

**Rationale:** `bg-primary` maps to `--color-primary: #02488D` in globals.css. Inactive uses `neutral-500` and `neutral-50` for consistency.

## Phase 3: Header Visual Polish & Smooth Transitions (Medium Priority)

**Files:** `src/components/layout/AppShell.tsx` (header element), `src/app/globals.css`

### 3.1 Fix header height consistency

**Current:**
```tsx
<header className="topbar ui-topbar ps-5 pe-5 py-4 shrink-0">
```

**Problem:** `.ui-topbar` defines `height: var(--navbar-height)` (72px) **plus** `py-4` (32px vertical padding) → actual height ~104px, inconsistent with design tokens.

**Fix:** Remove `py-4` inline padding; rely on `.ui-topbar` height + flex alignment:
```tsx
<header suppressHydrationWarning className="topbar ui-topbar ps-5 pe-5 shrink-0">
```

**Verification:** Header becomes exactly 72px tall, teal accent `border-top: 3px solid var(--primitive-cyan)` renders without clipping.

### 3.2 Add smooth visual transition: Header → Sidebar

**Problem:** Header is white frosted glass (`rgba(255,255,255,0.85)`), sidebar is dark navy (`#013A70`) → abrupt visual break.

**Solution: Add subtle bottom gradient to header** that transitions from white to semi-transparent before meeting sidebar:

```css
/* globals.css — update .ui-topbar */
.ui-topbar {
  position: sticky;
  top: 0;
  z-index: 50;
  border-bottom: 1px solid var(--neutral-200);
  border-top: var(--header-accent-line);
  height: var(--navbar-height);
  background: linear-gradient(
    to bottom,
    rgba(255, 255, 255, 0.98) 0%,
    rgba(255, 255, 255, 0.85) 100%
  );
  backdrop-filter: blur(20px);
  -webkit-backdrop-filter: blur(20px);
  box-shadow: var(--shadow-header);
  transition: all 0.3s;
}
```

**Effect:** Bottom edge of header subtly softens, creating a gradual blend into the dark sidebar rather than a hard line.

### 3.3 Optional: Role-aware header theming (deferrable)

For Owner/Gov roles with dark surfaces, could make header dark translucent to match:
```css
.theme-owner .ui-topbar,
.theme-gov .ui-topbar {
  background: linear-gradient(
    to bottom,
    rgba(1, 58, 112, 0.95) 0%,
    rgba(1, 58, 112, 0.85) 100%
  );
  border-bottom-color: rgba(255,255,255,0.1);
}
.theme-owner .topbar-title,
.theme-owner .sidebar-brand-name {
  color: #FFFFFF;
}
```
**Decision:** Defer to Phase 2 if needed; first implement universal white header.
