## 6. Behavioral Logic (User Flows)

### 6.1 Identity Management Flow

```
Unauthenticated State
    ↓
/login → Credentials Submit → Auth Store (setAuth)
    ↓
Token persisted in localStorage (Zustand persist)
    ↓
Session restored on page load (via persist middleware)
    ↓
/logout → Auth Store (logout) → Token cleared
```

**State Transition:**
- `user: null` → `user: User object`
- `token: null` → `token: JWT string`
- `role: null` → `role: 'Visitor' \| 'Owner' \| 'Gov' \| 'Carrier'`

### 6.2 Localization Flow

```
User triggers locale change (LanguageSwitcher)
    ↓
Router.push('/[locale]/...' with new locale
    ↓
LocaleLayout fetches messages via getMessages()
    ↓
LocaleProvider updates context with new messages
    ↓
t() function traverses message object for keys
    ↓
Components re-render with translated strings
```

**RTL Handling:**
- `dir` attribute set on `<html>` element
- CSS logical properties for directional styling
- `isRTL` flag exposed via `useLocale()` hook

### 6.3 Core Interactions

| Interaction | Logic |
|------------|-------|
| Search Filtering | InputField → onChange → parent handler → data filtering |
| Table Pagination | DataTableLayout state (currentPage, pageSize) → slice data |
| Sidebar Toggle | AppShell state (sidebarOpen) → conditional transform classes |
| Language Switch | LanguageSwitcher → router.push with new locale segment |
